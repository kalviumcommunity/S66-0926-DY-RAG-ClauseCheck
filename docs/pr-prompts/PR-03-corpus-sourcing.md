# PR 3 · Corpus sourcing, synthetic documents and the manifest

**Branch:** `a-corpus-sourcing` · **Owner:** Diya (Data, Retrieval & Platform Foundations) · **Week:** 1 · **Depends on:** PR 2

## Context

The corpus combines three real sources with synthetic documents:
- **CUAD** contracts (PDF, CC BY 4.0)
- **SEC EDGAR EX-10** exhibits, which include amendments (HTML)
- **public vendor DPAs and SLAs** (HTML)
- **synthetic** price schedules (DOCX with tables) and compliance certificates (TXT), generated with seed 42

Every document becomes one row in `data/manifest.csv`.

Read before starting:
- `docs/data/data-sourcing.md`, all of it, especially §8 (supplier repository), §9 (manifest conventions), §10 (pipeline) and §11 (exclusion rules)
- `docs/data/data-validation-report.md`, decisions DV-1 to DV-11
- `docs/requirements/PRD.md` §5 (corpus targets)

## Goal

Building the raw corpus takes one command. The manifest lists every document with its supplier, type, format, source, licence and checksum. A schema module defines the allowed values once, so every later PR validates against the same lists.

## Specification

### `clausecheck/core/schema.py`

Use the values from `data-sourcing.md` §9. If §9 names them differently, use §9's spelling, and the tests will still pass as long as these names exist:

```python
MANIFEST_COLUMNS: list[str] = [
    "doc_id", "supplier_id", "source", "doc_type", "format", "path", "title",
    "effective_date", "parent_doc_id", "licence", "url", "sha256", "is_synthetic",
]
SUPPLIER_COLUMNS: list[str] = ["supplier_id", "display_name", "aliases"]  # aliases joined by "|"
SOURCES: set[str] = {"cuad", "edgar", "vendor", "synthetic"}
DOC_TYPES: set[str] = {"contract", "amendment", "dpa", "sla", "price_schedule", "certificate"}
FORMATS: set[str] = {"pdf", "html", "docx", "txt"}
AMENDMENT_TYPES: set[str] = {"amendment"}  # rows of these types must have parent_doc_id
TARGETS: dict[str, tuple[int, int]] = {   # PRD §5 ranges (min, max)
    "contract": (120, 200), "amendment": (20, 40), "price_schedule": (30, 50),
    "compliance": (30, 50),  # dpa + sla + certificate
    "suppliers": (30, 50),
}
```

Manifest rules:
- `path` is relative to the repo root.
- `effective_date` is `YYYY-MM-DD` or empty. Follow DV-8 and DV-9 for conditional dates.
- `is_synthetic` is the string `true` or `false`.
- `doc_id` comes from `clausecheck.core.ids.doc_id(source, title)`.

### `scripts/fetch_sources.py`

Importable functions (the tests use them), plus `main(argv=None) -> int`:

- `edgar_headers(user_agent: str) -> dict[str, str]`: returns `{"User-Agent": user_agent, "Accept-Encoding": "gzip, deflate"}`. Raises `ValueError` if `user_agent` is empty or has no `@`, because SEC requires a contact email.
- `needs_download(path: Path) -> bool`: `True` if the file is missing or empty.
- `sha256_file(path: Path) -> str`
- `append_fetch_log(log_path: Path, row: dict) -> None`: columns `ts,source,url,status,bytes,sha256`. Writes the header only when it creates the file.
- `main` uses CLI flags `--only cuad|edgar|vendor` and `--limit N`. It respects EDGAR's limit of 10 requests per second (sleep at least 0.12 s between requests) and skips files already present. It selects documents using `data-sourcing.md` rules (CUAD: procurement types with labels in at least 3 procurement categories; EDGAR: EX-10 amendments chained to their parents; vendor: the documents named in §6). It writes `data/raw/{source}/...`, then **rebuilds** `manifest.csv` and `suppliers.csv` from what is on disk, including synthetic rows from `generate_synthetic.py`.
- CUAD rows record the CUAD JSON title. The loader in PR 4 uses CUAD's text when a PDF has no text layer (DV-2).

### `scripts/generate_synthetic.py`

- `generate(seed: int, out_dir: Path, suppliers: list[str] | None = None) -> list[dict]` returns manifest rows (all `MANIFEST_COLUMNS`) for the files it writes:
  - `price_schedule_<n>.docx`: a title paragraph, an effective date line, and **one table** with header `["SKU", "Description", "Unit price", "Currency", "Payment terms"]` and 5–15 rows
  - `certificate_<n>.txt`: certificate type (ISO 27001, SOC 2 Type II, ISO 9001), issuer, supplier name, certificate number, "Valid from YYYY-MM-DD", "Valid until YYYY-MM-DD"
- It also writes `out_dir/ground_truth.jsonl`, one line per fact: `{"doc_id", "field", "value"}`. These facts become the exact-value eval questions in PR 6.
- Use **only** `random.Random(seed)`, with no global random and no current time. The same seed must give identical text, rows and ground truth.
- `main(argv=None) -> int` with `--seed 42 --out data/raw/synthetic`.

### `tests/unit/test_manifest.py`

```python
"""The committed manifest is internally consistent."""
import csv
import hashlib
import re
from pathlib import Path

import pytest

from clausecheck.core import schema

ROOT = Path(__file__).resolve().parents[2]
MANIFEST = ROOT / "data" / "manifest.csv"
SUPPLIERS = ROOT / "data" / "suppliers.csv"


def _read(path: Path) -> list[dict]:
    with path.open(newline="", encoding="utf-8") as f:
        return list(csv.DictReader(f))


@pytest.fixture(scope="module")
def rows():
    assert MANIFEST.exists(), "data/manifest.csv must be committed"
    return _read(MANIFEST)


@pytest.fixture(scope="module")
def suppliers():
    assert SUPPLIERS.exists(), "data/suppliers.csv must be committed"
    return _read(SUPPLIERS)


def test_columns(rows):
    with MANIFEST.open(encoding="utf-8") as f:
        header = f.readline().strip().split(",")
    assert header == schema.MANIFEST_COLUMNS


def test_not_empty(rows):
    assert len(rows) > 0


def test_doc_ids_unique(rows):
    ids = [r["doc_id"] for r in rows]
    assert len(ids) == len(set(ids))


def test_allowed_values(rows):
    for r in rows:
        assert r["source"] in schema.SOURCES, r
        assert r["doc_type"] in schema.DOC_TYPES, r
        assert r["format"] in schema.FORMATS, r
        assert r["is_synthetic"] in {"true", "false"}, r
        assert (r["source"] == "synthetic") == (r["is_synthetic"] == "true"), r


def test_every_row_has_licence_and_checksum(rows):
    for r in rows:
        assert r["licence"].strip(), f"no licence: {r['doc_id']}"
        assert re.fullmatch(r"[0-9a-f]{64}", r["sha256"]), r["doc_id"]


def test_dates_are_iso_or_empty(rows):
    for r in rows:
        assert r["effective_date"] == "" or re.fullmatch(r"\d{4}-\d{2}-\d{2}", r["effective_date"]), r


def test_suppliers_known(rows, suppliers):
    known = {s["supplier_id"] for s in suppliers}
    unknown = {r["supplier_id"] for r in rows} - known
    assert not unknown, f"suppliers missing from suppliers.csv: {unknown}"


def test_parents_exist_and_match_supplier(rows):
    by_id = {r["doc_id"]: r for r in rows}
    for r in rows:
        if r["doc_type"] in schema.AMENDMENT_TYPES:
            assert r["parent_doc_id"], f"amendment without parent: {r['doc_id']}"
        if r["parent_doc_id"]:
            parent = by_id.get(r["parent_doc_id"])
            assert parent is not None, f"unknown parent for {r['doc_id']}"
            assert parent["supplier_id"] == r["supplier_id"], r["doc_id"]


def test_supplier_ids_and_aliases_unique(suppliers):
    ids = [s["supplier_id"] for s in suppliers]
    assert len(ids) == len(set(ids))
    seen = {}
    for s in suppliers:
        names = [s["display_name"]] + [a for a in s["aliases"].split("|") if a]
        for name in names:
            key = name.strip().lower()
            assert key not in seen or seen[key] == s["supplier_id"], f"alias '{name}' used twice"
            seen[key] = s["supplier_id"]


def test_files_exist_and_checksums_match(rows):
    if not (ROOT / "data" / "raw").exists() or not any((ROOT / "data" / "raw").iterdir()):
        pytest.skip("raw corpus not fetched on this machine")
    missing, wrong = [], []
    for r in rows:
        p = ROOT / r["path"]
        if not p.exists():
            missing.append(r["path"])
            continue
        if hashlib.sha256(p.read_bytes()).hexdigest() != r["sha256"]:
            wrong.append(r["path"])
    assert not missing, f"missing files: {missing[:10]}"
    assert not wrong, f"checksum mismatch: {wrong[:10]}"


@pytest.mark.targets
def test_corpus_targets(rows, suppliers):
    """May fail only if the shortfall is recorded in docs/data/data-sourcing.md."""
    count = lambda types: sum(r["doc_type"] in types for r in rows)
    actual = {
        "contract": count({"contract"}),
        "amendment": count({"amendment"}),
        "price_schedule": count({"price_schedule"}),
        "compliance": count({"dpa", "sla", "certificate"}),
        "suppliers": len({r["supplier_id"] for r in rows}),
    }
    for key, (lo, hi) in schema.TARGETS.items():
        assert lo <= actual[key] <= hi, f"{key}: {actual[key]} not in [{lo}, {hi}]"
    assert {r["format"] for r in rows} >= {"pdf", "html", "docx", "txt"}
```

### `tests/unit/test_synthetic.py`

```python
import importlib.util
import json
from pathlib import Path

import docx

from clausecheck.core import schema

ROOT = Path(__file__).resolve().parents[2]


def _load():
    spec = importlib.util.spec_from_file_location("generate_synthetic", ROOT / "scripts/generate_synthetic.py")
    mod = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(mod)
    return mod


def _content(out: Path) -> dict[str, str]:
    """Text content of every generated file (DOCX zips carry timestamps, so compare text)."""
    result = {}
    for p in sorted(out.iterdir()):
        if p.suffix == ".docx":
            d = docx.Document(p)
            parts = [para.text for para in d.paragraphs]
            for t in d.tables:
                parts += ["|".join(c.text for c in row.cells) for row in t.rows]
            result[p.name] = "\n".join(parts)
        else:
            result[p.name] = p.read_text(encoding="utf-8")
    return result


def _strip(rows):
    return [{k: v for k, v in r.items() if k != "sha256"} for r in rows]


def test_same_seed_same_output(tmp_path):
    gen = _load()
    rows_a = gen.generate(42, tmp_path / "a")
    rows_b = gen.generate(42, tmp_path / "b")
    assert _strip(rows_a) == _strip(rows_b)
    assert _content(tmp_path / "a") == _content(tmp_path / "b")


def test_different_seed_differs(tmp_path):
    gen = _load()
    gen.generate(42, tmp_path / "a")
    gen.generate(7, tmp_path / "b")
    assert _content(tmp_path / "a") != _content(tmp_path / "b")


def test_rows_are_valid_manifest_rows(tmp_path):
    rows = _load().generate(42, tmp_path / "out")
    assert rows
    for r in rows:
        assert list(r.keys()) == schema.MANIFEST_COLUMNS
        assert r["source"] == "synthetic" and r["is_synthetic"] == "true"
        assert r["doc_type"] in {"price_schedule", "certificate"}
        assert r["format"] in {"docx", "txt"}


def test_price_schedules_have_one_table_with_header(tmp_path):
    out = tmp_path / "out"
    _load().generate(42, out)
    files = list(out.glob("price_schedule_*.docx"))
    assert files
    for p in files:
        tables = docx.Document(p).tables
        assert len(tables) == 1
        header = [c.text for c in tables[0].rows[0].cells]
        assert header == ["SKU", "Description", "Unit price", "Currency", "Payment terms"]
        assert 5 <= len(tables[0].rows) - 1 <= 15


def test_ground_truth_matches_rows(tmp_path):
    out = tmp_path / "out"
    rows = _load().generate(42, out)
    ids = {r["doc_id"] for r in rows}
    lines = [json.loads(l) for l in (out / "ground_truth.jsonl").read_text().splitlines() if l]
    assert lines
    assert all({"doc_id", "field", "value"} <= l.keys() for l in lines)
    assert {l["doc_id"] for l in lines} <= ids
```

### `tests/unit/test_fetch_sources.py`

```python
import csv
import importlib.util
from pathlib import Path

import pytest

ROOT = Path(__file__).resolve().parents[2]


@pytest.fixture(scope="module")
def fs():
    spec = importlib.util.spec_from_file_location("fetch_sources", ROOT / "scripts/fetch_sources.py")
    mod = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(mod)
    return mod


def test_edgar_headers_require_contact_email(fs):
    assert fs.edgar_headers("Diya diya@example.com")["User-Agent"] == "Diya diya@example.com"
    with pytest.raises(ValueError):
        fs.edgar_headers("")
    with pytest.raises(ValueError):
        fs.edgar_headers("no-email-here")


def test_needs_download(fs, tmp_path):
    p = tmp_path / "x.pdf"
    assert fs.needs_download(p)
    p.write_bytes(b"")
    assert fs.needs_download(p)
    p.write_bytes(b"%PDF")
    assert not fs.needs_download(p)


def test_sha256_file(fs, tmp_path):
    p = tmp_path / "a.txt"
    p.write_bytes(b"abc")
    assert fs.sha256_file(p) == "ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad"


def test_fetch_log_header_written_once(fs, tmp_path):
    log = tmp_path / "fetch_log.csv"
    row = {"ts": "t", "source": "cuad", "url": "u", "status": 200, "bytes": 3, "sha256": "s"}
    fs.append_fetch_log(log, row)
    fs.append_fetch_log(log, row)
    with log.open() as f:
        rows = list(csv.DictReader(f))
    assert len(rows) == 2
    assert log.read_text().count("ts,source,url,status,bytes,sha256") == 1
```
